# Site Diego Mudanças

Site estático (HTML + CSS + JS), sem build. Abra `index.html` ou publique a pasta `site/` em qualquer hospedagem (Netlify, Vercel, GitHub Pages, Hostinger...).

- **Contatos:** edite só `config.js` (WhatsApp, Instagram, site, cidade).
- **Vídeos:** troque os arquivos em `media/` (mantenha o nome ou ajuste o `index.html`).
- **Fotos:** `assets/`.
- Os vídeos e fotos vêm dos materiais enviados e dos filmes produzidos neste projeto.
